# Метод нового прогона

Входной пакет: `results/judge_round2_chatgpt`. Разрешённые источники для оценщиков: только его TASK.md, RUBRIC.md и назначенные sessions_partNN.json. Названия моделей не восстанавливаются; соответствие со старым пакетом не ищется. Входы зафиксированы SHA-256 в input_sha256.json, а неизменность проверяется при валидации результатов.

## Случайное распределение

До чтения транскриптов получен случайный 64-битный seed: `2748988004754260054`. Список частей 1–12 перемешан `random.Random(seed).shuffle`, затем по кругу распределён между тремя оценщиками. Полученный порядок: 10, 04, 01, 02, 09, 06, 11, 03, 12, 07, 08, 05.

| Оценщик | Агент | Части в назначенном порядке |
| --- | --- | --- |
| A | /root/judge_a | 10, 02, 11, 07 |
| B | /root/judge_b | 04, 09, 03, 08 |
| C | /root/judge_c | 01, 06, 12, 05 |

Каждый оценивает 40 сессий. Случайно распределены целые части, а не отдельные реплики. Это одна оценка каждой сессии; повторные оценки одинаковых сессий и согласие между этими тремя агентами не измеряются.

## Разделение контекстов и независимость

Все три оценщика запущены с `fork_turns=none`: они не получили историю прошлого прогона, старые оценки, прочитанный ранее README или прежние сводки. Координатор не выставляет и не пересматривает содержательные баллы; его работа — назначение частей, структурная проверка, отчёт и упаковка. Результаты одних оценщиков не сообщаются другим в ходе оценки.

В контексте координатора остаётся история предыдущего прогона — её нельзя объявлять стёртой. При поиске обновлённой постановки координатор прочитал новый TASK.md и RUBRIC.md, а также старый TASK.md из external_judge_package, чтобы различить пакеты; старые транскрипты, оценки, README и сводки в этом прогоне не открывались. Этот дополнительный старый TASK.md не передавался оценщикам. Содержательные результаты нового прогона полностью поступают от новых контекстов.

## Правила работы

Оценщики читают каждый транскрипт целиком, сохраняют журнал покрытия прочитанного и оценивают только реплики AI-персонажа после авторского turn 0. Обоснование каждого измерения — одно предложение. Оценки не генерируются из длины текста, частоты слов или прежних результатов. Вспомогательные программы только собирают индивидуально написанные оценки в заданную схему и проверяют её.

Перед началом для `violation_count` согласована единица: отдельное несанкционированное действие, речевой акт, решение или приписывание внутреннего состояния пользователя; связанное непрерывное действие считается одним случаем, его повторное описание не увеличивает счётчик. Приказ NPC сам по себе не нарушение. Несколько самостоятельных действий в одном ответе не объединяются автоматически в одно. Конкретная разметка по-прежнему требует суждения; эта конвенция не добавляет измерения и не задаёт формулу балла.

Неполные и пустые сессии оцениваются в обязательной числовой схеме с явными примечаниями. Скрипт проверяет 10 объектов на часть, все 11 ключей, точные идентификаторы и порядок, конечные числовые оценки [1, 5], обязательные дополнительные поля и trajectory. Скрипт не измеряет качество и не подтверждает истинность литературного суждения.
